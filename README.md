# Kumar Oil Mill

Oil mill management app (React, Vite, Supabase, Tailwind).

## Push to GitHub

GitHub repo names **cannot include apostrophes**, so the repo is **`kumars_oil_mill`** (for the folder `kumar's shop`).

1. Install [Git](https://git-scm.com) and [GitHub CLI](https://cli.github.com).
2. Run once: `gh auth login`
3. In PowerShell:

```powershell
& "e:\project\kumar's shop\scripts\push-to-github.ps1"
```

Or double-click: `e:\project\setup-kumar-oil-mill-github.bat`

`.env` is gitignored and will **not** be uploaded.
